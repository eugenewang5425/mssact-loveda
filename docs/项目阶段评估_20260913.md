# 项目阶段评估（2026-09-13）

> 依据：本项目已完成的全部实验、已定位的全部失误、以及当前未完成项。
> 结论先行：**当前处于"阶段二的后半段"——诊断部分已完成，修复与复评尚未开始。**

---

## 一、三阶段划分（沿用你的定义）

| 阶段 | 特征 | 核心问题 |
|---|---|---|
| **一** | 毕业论文时期 + 专用 LoveDA 早期 | **盲目**探索模型架构与训练策略 |
| **二** | 探索架构**原理与有效性** + 提升训练效率 | 模块到底在不在工作？为什么这么快/慢？ |
| **三**（下一个） | 更广泛学习模型知识、优化架构、面向高光谱/多光谱设计并验证 | 多光谱/高光谱下模型该如何设计？ |

判断一个项目处于哪个阶段，不看做了什么实验，而看**判断依据的性质**：
- 阶段一：依据是"跑出来的数字"（**结果导向**，无法归因）
- 阶段二：依据是"可证伪的机制"（**原理导向**，能归因）
- 阶段三：依据是"跨任务/跨模态的规律"（**迁移导向**）

## 二、阶段一的确证（本项目早期确实处于阶段一）

用"是否做过机理验证"这把尺子回看早期工作，证据充分：

| 证据 | 性质 |
|---|---|
| 模型架构（EMR/ECSAM/FPN/Transformer/Adapter）**从未验证过各模块是否在工作** | 盲目——直到本次才用数值实验证明 FPN 的多尺度融合被丢弃、Transformer 无位置编码 |
| 训练策略靠**试错**（`strat_*` 系列 11 组：不同 LR、预算、调度） | 盲目——没有分离"调度效应"与"架构效应"的手段 |
| 类别体系凭直觉假设，`0`（no-data）被当作背景参与训练与评估 | 盲目——未按官方文档逐条核对 |
| 研究区选择由"手头有什么影像"决定（GF-1 2.4 m + 根河市），类别不可分 | 盲目——未由分类体系的可分性决定 |
| **全部比较基于单次运行**，无误差条 | 盲目——"差异"与"噪声"无法区分 |
| 基线带 ImageNet 预训练却未察觉（`weights=None` 未关闭 `weights_backbone`） | 盲目——只验证了自己假设的那个参数 |

**阶段一的典型症状是"结论无法归因"**：能报出数字，但说不清数字来自架构、调度、
数据还是混淆变量。以上六条都符合。

## 三、阶段二的进展（已完成的部分）

阶段二的核心任务是**从"结果导向"转为"机制导向"**。本项目已完成四件事：

### 3.1 建立误差底线 —— 阶段二的地基

实测 σ_seed = **0.0050**（同配置 4 个种子）。这是本项目方法学上最重要的产出：
**没有它，任何 ΔKappa 都不可解释**。有了它，"模块无差异"从推断变为**测量**，
并可对全部设计选择给出统一分级（报告 §5.11）。

### 3.2 用可证伪的机制取代"跑数字"

| 问题 | 阶段一的做法 | 阶段二的做法 |
|---|---|---|
| 模块是否在工作？ | 做消融，看 Kappa 变化 | **数值实验**：归零 FPN 支路后输出差**恰好 0.0**；置换 token 后差 7.15e-07 |
| 基线为何领先？ | 归因于架构（低层跳连） | **权重级取证**：与官方文件逐张量比对，264/265 相同；再跑从零对照推翻原结论 |
| 指标为何看不见边界？ | 报告边界像素占比（且占比算错了） | **oracle 作弊实验**：量化"完美解决边界"仅值 +0.016 Kappa |
| 收敛快是架构还是调度？ | 看第几轮收敛 | **累计学习量**（LR 积分）：把调度效应从架构效应中剥离 |

### 3.3 训练效率（阶段二的另一半）

| 指标 | 优化前 | 优化后 |
|---|---|---|
| GPU 利用率 | 49.9% | **84.3%** |
| 每轮耗时 | 144 s | **14.7 s** |
| 数据阶梯每张图 | ≈170 ms | **≈24 ms** |

且**零性能损失**（回退验证 0.6293 vs 旧管线 0.6277），并明确了加速来源是
**memmap 预解码**而非并发改动。

### 3.4 可复现性基建 —— 阶段二向阶段三过渡的前提

`paths.py` 路径集中（脚本零绝对路径）、`experiments_index.json` 实验索引、
`FACTS.json` 事实单一来源、管线世代隔离、推送前审核、报告内容自检。
**没有这些，阶段三的多模态实验会重复阶段一的混乱。**

## 四、阶段二的未完成项（为什么还不能进入阶段三）

| # | 未完成项 | 为什么它是阶段二的门槛 |
|---|---|---|
| 1 | **三处架构缺陷尚未修复** | 消融实验在当前实现下**不可解释**——衡量的是"移除无效计算的影响"，不是"模块有效性"。修完重评，消融才有意义 |
| 2 | **TOST 等效性检验未做** | 目前只能说"未达显著"，不能说"统计等效"。这是阶段二"机理结论"的最后一块拼图 |
| 3 | **种子数仅 4**（文献建议 ≥10） | σ_seed 目前只支持量级判断，不支持精确检验 |
| 4 | **缺陷检验只在 light 配置上做** | 大配置未复跑，结论的适用范围未完全闭合 |

**这四项都不是新方向的探索，而是现有方向的收尾**——因此当前**仍属阶段二**。

| 顺序 | 工作 | 预期产出 | 成本估计 |

## 六、阶段三的入口（已具备的条件与待补的能力）

### 6.1 已具备

- **可信的评价框架**：σ_seed、从零对照、管线世代隔离、TOST 就绪
- **可执行的修复路径**：三处缺陷已定位到代码行，修复方案明确
- **已知的最大杠杆**：预训练（+0.054~0.154）≫ 训练策略（+0.020~0.022）> 模块（≤0.006）
- **结论的迁移起点**：本项目已证明"标签质量决定指标上限"，这在多光谱任务上只会更突出

### 6.2 待补（阶段三需要的新能力）

| 能力 | 说明 |
|---|---|
| **多光谱/高光谱数据管线** | 现有管线假设 3 波段 RGB（`REMAP`、`mean/std`、patch embedding 均为 3 通道） |
| **光谱-空间联合注意力** | 现有 ECSAM 只做水平/垂直两个**空间**方向；需扩展为光谱/空间/通道**三方向池化** |
| **波段数可变的架构** | FPN 横向连接、Transformer patch embedding 均需适配任意波段数 |
| **跨模态验证协议** | 高光谱数据集上的从零基准与误差底线（避免重演本项目的归因错误） |

### 6.3 两条已在报告中排定的方向（报告 §8.1）

1. **换用预训练主干**：把 EMR 编码器替换为有预训练权重的骨干，回答
   "自研架构 + 预训练特征"能否超过"标准架构 + 预训练特征"。
2. **域内预训练**：用 LoveDA 影像做自监督（MAE/SimCLR/DINO），或用官方数据集的
   另一分区（val 区 1,669 张**带标注**，与本地划分天然不重叠）做跨区预训练。

> ⚠️ 两条都需**重新设计数据预算对照**（预训练用掉的数据不能同时用于微调），
> 否则会重演"数据量 vs 预训练无法分离"的混淆。

## 七、结论

**你的判断正确：本项目处于阶段二。** 更精确地说：

> **阶段二的"诊断"部分已经完成，"修复与复评"部分尚未开始。**

理由：阶段二的标志是"以可证伪的机制为依据"。本项目已经做到——
三处缺陷被数值证明、预训练混淆被权重级取证推翻、误差底线被实测、
效率瓶颈被定位并修复。但**缺陷仍未修复**，因此在修复前，
**消融实验尚不具备可解释性**，这也是进入阶段三前必须闭合的一环。

**建议**：按第五节的 6 步清单收尾阶段二（约 1–2 天机时），
再以"多光谱三方向池化 + 预训练主干"为入口进入阶段三。

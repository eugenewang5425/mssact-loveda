## 三、逐节审核

> 每条格式：**[编号][严重度][质疑维度]** 引文/位置 → 质疑与分析。引文为节选，"……"省略。

### 3.1 摘要

**[Q-01][B][结论]** "同配置换随机种子（n=4）得到 σ_seed = 0.0050、极差 0.0094。以此为尺度衡量全部实验差异后，可分辨的效应屈指可数。"
- 质疑：σ_seed 在一个协议（val 256² 裁剪）、一个预算（60 轮）、一条管线（P-MEM-ROLL）、一个数据档（全量）上测得，摘要却宣布它是"全部实验差异"的尺度。报告后文自己实测了整图协议 σ=0.0041、并承认判读依协议而变（§5.6.16），说明"统一尺度"并不统一。此外 §5.7 写明"裁剪位置由 epoch_seed 决定，与 seed 无关"——该 σ_seed 只含初始化与 shuffle 顺序的方差，**不含增强路径方差**，因此 0.0050 是复制噪声的**下界**，用它判"不可分辨"系统性偏乐观。
- 分析：摘要应写明 σ_seed 的适用域（协议/预算/世代三元组），并声明其为下界。

**[Q-02][B][推理]** "极差 0.0094。……同管线模块消融的总散布 0.008 仅为种子极差的 0.87 倍——即换一个随机种子带来的波动，比整套架构改动带来的差异还大。"（§4.3.4、§5.7 同口径）
- 质疑：三个数字互相咬合不上。§4.3.4 表内 8 个 Δ 的极差 = +0.0057 −(−0.0040) = **0.0097**，不是 0.008；0.0097/0.0094 = 1.03 而非 0.87。若"散布"指标准差，8 个 Δ 的 std ≈ 0.0031–0.0033，也不是 0.008。"散布 0.008"的口径全文未定义，却支撑了"消融 < 种子噪声"这一被写进摘要与 §0 的核心判断。
- 分析：需定义口径（极差/半极差/std）并重算。这是少数几处"数字本身对不上"的地方。

**[Q-03][A][结论]** "在公平的从零对照下，自研 6.10M 与 DeepLabV3+ 39.63M 不可分辨（Δ = +0.0039，0.78σ）。"
- 质疑：同一比较在 §4.3.2 是 自研 0.6312 vs 从零 DeepLab **0.6281**（自研高 +0.0031），在 §5.6.6 是 0.6320 vs **0.6359**（DeepLab 高 +0.0039）。**符号随世代翻转**（P-PNG vs P-MEM-ROLL），两处均未在表旁标注世代，摘要只引用了其中符号有利表述的一个数（+0.0039）。两个世代各自都不显著，这一点结论成立；但"Δ=+0.0039"作为唯一引用值具有选择性。
- 分析：两处数字都应标注世代，摘要应写成"跨两代为 −0.0031~+0.0039，均 <1σ"。

**[Q-04][A][推理]** "项目早期因 weights=None 未关闭主干预训练……导致'+0.0720 架构优势'的错误归因——该错误已定位、更正并记录取证过程。那 0.0720 中约 95% 来自预训练主干。"（§5.6.6）
- 质疑：95% = (0.0720−0.0039)/0.0720，是**可加性假设**下的点算术：预训练效应 + 残余架构效应之和恰等于旧观测差。单次运行之差的种子层噪声按报告自己的口径是 √2σ≈0.0071，相当于 0.0720 的 10%——95% 的分母分子都带着同量级的不确定性却未传播。诚实的写法是"绝大部分（约九成以上）"。
- 分析：方法（取证）无可挑剔；结论表述（精确百分数）超出数据支持。

**[Q-05][A][一致性]** "四、训练策略的收益可分辨，架构模块增删不可分辨。……全部模块消融都 ≤1.13σ。"
- 质疑：与摘要第三条自相矛盾——第三条刚说明整图测试协议下 8 变体"全部为负、5 个可分辨（如 −0.0202 = 4.92σ）"。第四条的无限定全称句在报告自己的证据下不成立（Transformer/ECSAM 在 test_clean 协议 4.9σ/6.4σ，**超过**第四条引以为据的裁剪策略 3.8–4.5σ）。第五条的杠杆排序"预训练主干 ≫ 训练策略 > 架构模块"同样未注协议。
- 分析：摘要第三条已经给出了正确限定，第四、五条却未同步。这是"任何'无差异'表述都必须注明协议"（§5.6.16 自己的规则）在摘要层的违例。

**[Q-06][B][观点]** "六、标签质量仍是评价上限的约束。模型间一致率 0.7589 显著高于模型与人工标签的 0.6495。"
- 质疑：①"显著高于"没有给出任何统计检验（配对 per-image 差值的检验并不难做）；②6 个模型的入选未说明是否预登记——剔除 SegFormer（0.3043）与 PSPNet（0.5175）本身就会抬高模型间一致率，而弱模型恰是检验"好模型彼此一致"所必需的对照；③同训练集、同损失、同协议的模型共享偏置，一致率高于对标签一致率**不必然**指向标签噪声（也可能只是同族偏差）。§5.3 对③已自我限定为"提示性证据"，但摘要的"仍是评价上限的约束"是断言语气，强于其证据分级。
- 分析：摘要措辞降为"提示性"；或在 §5.3 补一个配对检验。

**[Q-07][C][一致性]** "三、……四处结构性缺陷……" 与 §1.1"发现了三处实现缺陷"、§5.6 引言"三处结构性缺陷"、§9.4"三处架构实现缺陷"。
- 质疑：§5.6 表格实列 **4 行**（D1/D2/D3/D5），摘要说"四处"正确，正文三处"三处"均漏数 ecsam[0]。另：缺陷编号从 D3 直接跳到 D5，**D4 缺号无任何解释**。

### 3.5 §5.1–§5.5

**[Q-16][✓][—]** §5.1 对 A→B→C 混合效应的诚实声明（"三者无法分离"）是正确且难得的，审核无异议。唯一补充：§5.1 末"道路 +0.390、水域 +0.385"援引阶段 B 数据并已标注"只宜作为趋势参考"，处理得当。

**[Q-17][A][方法]** §5.2"方法（以及它为什么能分离两者）：OneCycleLR 的学习率轨迹是解析已知的……定义累计学习量 S(t)=Ση_τ。若两个模型在同一水平上所需的 S 相同，则差异来自架构……"
- 质疑：**该方法在单一共享调度下无法分离任何东西。** 同一次 60 轮 OneCycle 中，S(t)/S(T) 是 t/T 的确定函数（单调、与模型无关）。"达 K0.5 累计学习量 59.7%"只是"第 21/60 轮过阈"的重新参数化——把轮次乘以一个固定单调函数，不产生新信息，更谈不上把"调度效应"从"架构效应"中分离。要分离调度与架构，至少需要**不同调度**下的对照（项目后来在 §5.6.14 发现 best@49/best@109 恰由退火终点决定，反而印证了"收敛轮次是调度的函数"这一平凡性）。表中真正有信息量的对比只有"预训练 11 轮 vs 从零 28 轮"，而这不需要 S(t) 任何包装。
- 连带：§9.3"建立累计学习量方法分离调度效应与架构效应"是方法学过称；§5.2 结论句"支持'第几轮收敛主要由调度曲线决定'这一判断"在共享调度设计下接近循环论证。
- 分析：建议将 §5.2 降级为描述性呈现（"各模型过阈轮次对照"），删除"分离"声明；或补一个真正的跨调度实验（60 轮 vs 120 轮同模型已现成）。

**[Q-18][B][推理]** §5.2"DeepLabV3+ 需要 75.9% 的累计学习量，比自研模型的 59.7% 还慢。……在公平的从零条件下，DeepLabV3+ 的收敛速度不优于自研模型。"
- 质疑：两处过阈点均为单种子单次运行，过阈轮次本身不带误差棒；28 轮 vs 21 轮之差对单轮内 val Kappa 的噪声敏感。"不优于"措辞尚可，但"更慢"（§6.2 第二条"从零条件下它更慢"）是点估计比较。按全文自己的标准，这属于"弱证据"级。
